Installation

The PyExperimenter package requires Python 3.10 or newer and can be easily installed via PyPI:

pip install py-experimenter

Thereby, the following dependencies are automatically installed:

dependencies = [
    "numpy>=1.26",
    "pandas>=2.0",
    "joblib>=1.2.0",
    "codecarbon>=3.0",
    "pymysql>=1.0.3",
    "omegaconf>=2.3.0",
]

Note

To run the example notebooks, a Jupyter environment is required, which is not installed automatically. It can be installed e.g. via pip install jupyterlab.
